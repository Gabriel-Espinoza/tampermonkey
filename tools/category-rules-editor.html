Instrucciones rápidas
  1. Ejecuta python3 tools/build_category_rules_editor.py para refrescar categorías desde YNAB.
  2. Carga shared/category-rules.js con el botón superior.
  3. Edita Exact / Patterns / Skip.
  4. Teclado: Enter/Shift+Enter sube/baja filas, Ctrl+flechas navega celdas, Tab respeta salto entre filas.
